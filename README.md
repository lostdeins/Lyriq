# Lyriq — Word-by-Word LRC Maker

**Lyriq** is a free online tool for creating word-by-word synchronized LRC files with millisecond precision. Perfect for karaoke, lyric videos, and any project that needs word-level timed lyrics.

👉 **Try it live:** [https://lostdeins.github.io/Lyriq/](https://lostdeins.github.io/Lyriq/)

## ✨ Features

- 🎯 **Word-by-word and line-by-line sync** — stamp timestamps with millisecond precision.
- 🎵 **Speed and pitch control** — slow down the track (0.5× – 2×) with vinyl-style pitch shift for easier timing.
- ✏️ **Manual timestamp editing** — built-in editor with fine-tuning (±50 ms) and quick-copy from neighbors.
- 🌗 **Dark and light themes** — Material You (Material Design 3) styling.
- 🌐 **Bilingual interface** — English and Russian, switchable on the fly.
- 🎧 **Wide audio support** — MP3, WAV, FLAC, OGG, AAC.
- 💾 **One-click LRC export** — download the finished file instantly.
- 📱 **Responsive** — works on desktop and mobile.

## 🚀 Quick Start

1. Open [Lyriq](https://lostdeins.github.io/Lyriq/).
2. Load an audio file (click **Open** or drag & drop).
3. Paste the lyrics and click **Parse text**.
4. Set timestamps with the **STAMP** button or the **Space** key.
5. Click the **Export LRC** button to download your synchronized file.

## 🎹 Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `Space` | Set timestamp for current word / line |
| `Backspace` | Undo last timestamp |
| `P` | Play / pause |
| `←` / `→` | Seek −3 s / +3 s |
| `Shift` + click | Jump to a word's timestamp |

## 🛠️ Tech Stack

- Pure HTML, CSS, and JavaScript — no build step, no dependencies.
- Material Design 3 (Material You) with dark and light palettes.
- Web Audio API for playback rate and pitch handling.

## 📦 Local Setup

Just download `index.html` and open it in any modern browser. That's it — no server, no installation required.

```bash
git clone https://github.com/lostdeins/Lyriq.git
cd Lyriq
# then open index.html in your browser
```
